# Concept Test Plan V1

## 1. Test Objective

验证用户是否能够理解并使用：

- Readiness 状态
- Evidence / Evidence-linked Findings
- Overall Gate
- Next Action

并基于 Prototype 完成一次复现前准备判断。

## 2. Test Method

形式：异步任务测试

流程：

用户查看 Prototype → 完成固定任务 → 在对应测试记录中填写答案。

## 3. Participants

2–3 名目标用户或模拟用户。

## 4. Test Task

基于 FGI 复现案例，使用 ResearchOps 判断：

1. 当前是否适合开始复现；
2. 影响当前判断的主要问题是什么；
3. 系统判断是否有可查看的 Evidence 支撑；
4. 下一步最应该做什么。

## 5. Observation Focus

重点观察：

- 是否理解 Overall Gate，尤其是 Conditional Proceed；
- 是否能找到影响判断的关键 Readiness 问题；
- 是否主动查看 Evidence，并能理解其与 Finding 的关系；
- 是否理解 Next Action；
- 是否存在明显的理解或操作困难。

## 6. Test Records

测试题目直接写入以下三个用户记录文件，不再单独建立 User Test Form：

- `Raw_Records/P01_Response.md`
- `Raw_Records/P02_Response.md`
- `Raw_Records/P03_Response.md`

Day 6 仅准备测试材料；Day 7 执行 Concept Test 后填写实际答案。

本次 Concept Test 用于验证用户理解与使用行为，不据此提前宣布 H2 / H3 通过。
