# Baseline Evaluation Rubric

Rubric ID: Baseline Rubric V1
Version: V1
Freeze Date: 2026-08-10
Status: FREEZE

Applicable Baselines:
- Baseline A｜通用大模型自由对话
- Baseline B｜人工现有流程
- Baseline C｜Codex

Purpose:
用于对 A / B / C 在相同 FGI 复现准备判断任务下的输出质量进行一致评价。

评分采用 0 / 1 / 2 锚点。
每个质量维度必须同时记录评分依据，不允许仅凭整体印象打分。

---

## 1. 决策完整性

### 0 分
没有明确给出“继续 / 有条件继续 / 暂停”，
或最终决策与现有材料和用户约束明显冲突。

### 1 分
给出了明确决策，
但缺少影响该决策的关键条件说明。

### 2 分
决策明确，
并与关键材料、用户条件和约束保持一致。

---

## 2. 关键缺失 / 阻塞识别

### 0 分
遗漏多数影响当前复现决策的关键缺失项或阻塞。

### 1 分
识别了部分关键缺失项或阻塞，
但仍存在明显重要遗漏。

### 2 分
识别了当前主要阻塞以及对决策具有高影响的未知信息。

---

## 3. 证据可追溯性

### 0 分
关键结论没有来源，
或提供的来源无法定位、无法支持对应结论。

### 1 分
部分关键结论能够找到来源，
但仍有重要判断缺乏可定位依据。

### 2 分
关键结论均具有可定位依据，
并能够明确区分材料事实与基于事实形成的推断。

---

## 4. 未知项处理

### 0 分
将未知信息当作已知事实，
或在证据不足时自行猜测。

### 1 分
能够指出“不确定”或“未知”，
但没有说明如何以最小成本补齐或验证该信息。

### 2 分
明确标记关键未知，
并给出最少必要的补充问题或验证方式。

---

## 5. 风险完整性

### 0 分
忽略影响复现准备判断的重要风险，
例如数据、权重、环境、算力或评测等关键风险。

### 1 分
能够识别部分主要风险，
但覆盖范围或优先级仍存在明显不足。

### 2 分
主要风险覆盖充分，
并能够根据其对当前复现决策的影响进行基本排序。

---

## 6. 行动可执行性

### 0 分
建议泛化，
无法据此立即开始下一步行动。

### 1 分
提供了具体步骤，
但优先级、依赖关系或前置条件不清楚。

### 2 分
前三步行动明确，
按照基本依赖或优先级排序，
用户可以据此直接开始执行。

---

## 7. 时间 / 交互成本

本维度不进行 0 / 1 / 2 主观评分。

统一记录：

- 总耗时；
- 是否超时；
- A / C 用户主动追问轮次；
- B 搜索次数；
- B 材料切换次数；
- 搜索 / 工具使用情况；
- 明显等待、报错或人工干预情况。

该维度用于比较不同 Baseline 的效率与交互成本，
不得与质量评分混为一个总分。


## Scoring Rules

1. 每个质量维度均独立评分，不得根据“整体感觉”反推各维度得分。

2. 每个 0 / 1 / 2 分必须附至少一条具体评分依据，
   指向 Baseline 的实际输出或过程记录。

3. 不因输出篇幅长、语言流畅或表达专业而自动提高评分。

4. 不因某个 Baseline 属于 AI、人工或 Codex 而调整评分标准。

5. 评分时使用相同的 Rubric V1，不允许测试后针对某个对象改变锚点。

6. 后续分析重点保留各维度差异，
   不使用单一总分替代“在哪个决策断点失败、为什么失败”的分析。
