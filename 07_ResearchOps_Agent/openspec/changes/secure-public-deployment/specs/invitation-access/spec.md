# Spec Delta

## Purpose

为仅向少数受邀人员开放的 ResearchOps 提供无需注册的访问入口。通过可独立撤销的邀请码和安全会话保护业务接口，并使运维人员能够在本机管理访问资格，无需公开管理员后台。

## ADDED Requirements

### Requirement: 本地管理邀请码
系统 SHALL 提供本地管理入口，支持生成、列出元数据、设置到期时间与额度、停用邀请码。邀请码 MUST 具有至少 128 位随机熵，仅在生成时展示一次，持久化存储与常规查询不得返回明文。

#### Scenario: 生成并查看邀请码
- **WHEN** 运维人员生成邀请码并随后列出邀请码
- **THEN** 生成操作展示一次明文及稳定主体 ID，列表仅展示 ID、标签、状态、到期时间和额度，不展示明文或摘要

### Requirement: 邀请码兑换会话
系统 SHALL 允许访客提交有效邀请码而不注册账号，兑换绑定该邀请码主体的会话；无效、停用及到期邀请码 MUST 返回相同的通用失败信息且不签发会话。

#### Scenario: 有效邀请码进入
- **WHEN** 访客提交有效且未到期的邀请码
- **THEN** 系统签发新会话并进入评估页面，不要求邮箱、密码或第三方账号

#### Scenario: 不泄露邀请码状态
- **WHEN** 访客提交不存在、已停用或已到期的邀请码
- **THEN** 系统统一返回 401 和通用提示，不说明该码是否曾经存在

### Requirement: 会话安全与撤销
公网会话 MUST 使用不可预测的令牌及 Secure、HttpOnly、SameSite=Strict、Path=/ 且无 Domain 的 Cookie，具有绝对有效期且不超过邀请码到期时间。退出、邀请码停用或到期后，会话 MUST 无法继续访问业务 API；原始令牌不得持久化为明文。

#### Scenario: 停用立即阻止后续访问
- **WHEN** 运维人员停用一个已有多个会话的邀请码
- **THEN** 其所有会话的下一次业务请求均返回 401，其他邀请码会话仍可使用

#### Scenario: 退出并清理浏览器状态
- **WHEN** 用户退出会话
- **THEN** 服务端撤销该会话，浏览器清除 Cookie 及当前评估界面状态，重放旧 Cookie 返回 401

### Requirement: 全部业务接口统一保护
公网部署 MUST 对全部业务 API 校验会话，包括目标解析、计划、评估、进度、历史、反馈和最终决定。匿名白名单 SHALL 仅包含登录入口及必需静态资源、会话兑换和最小存活检查；开发文档及 API schema MUST 禁止公网匿名访问。

#### Scenario: 绕过网页直接调用
- **WHEN** 未登录调用方直接请求任一业务 API
- **THEN** 系统返回 401，不运行目标解析、模型、环境探测或任务创建

#### Scenario: 页面入口与受保护资源
- **WHEN** 未登录访客打开 `/mvp/` 或直接请求 `/docs`、`/redoc`、`/openapi.json`
- **THEN** 页面提供邀请码入口而不展示历史评估，开发文档及 schema 不对匿名访客开放

### Requirement: 公网模式失败关闭
系统 SHALL 默认启用访问控制；显式本地开发模式才可免认证，且 MUST 仅绑定回环地址。公网配置缺失、安全存储不可用或请求时身份校验失败 MUST 拒绝业务访问，不得自动降级为匿名模式。

#### Scenario: 安全状态不可用
- **WHEN** 公网服务启动或处理请求时无法访问身份状态
- **THEN** 服务拒绝启动或返回通用 503，不绕过认证且不触发付费模型调用
