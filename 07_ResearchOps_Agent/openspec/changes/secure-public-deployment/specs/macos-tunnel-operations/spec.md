# Spec Delta

## Purpose

使 Mac mini 上的 ResearchOps 能通过指定 Cloudflare Tunnel 稳定提供受控的公网服务，并让配置、日志、启动前提和回滚过程可检查。验收同时覆盖安全拒绝和合法访问，避免以进程存在或匿名页面返回 200 代替服务可用性。

## ADDED Requirements

### Requirement: 回环源站和有限隧道入口
公网部署的 FastAPI MUST 仅监听回环地址并以非 root 身份运行；隧道 SHALL 仅将 `researchops-agent.com` 转发到本机源站，未匹配主机返回 404，不暴露管理端口、指标端口或其他本地服务。

#### Scenario: 局域网不能直达源站
- **WHEN** 部署完成后分别从本机回环地址、局域网其他设备及公网域名访问
- **THEN** 回环和隧道入口可按访问策略工作，局域网不能通过 Mac 的非回环地址访问 8000 端口

### Requirement: 隧道启动显式且凭证最小化
常驻隧道 MUST 使用绝对可执行路径、显式配置路径和隧道 UUID 启动，不依赖 root HOME 的隐式发现。运行时 SHALL 仅部署现有隧道所需凭证，凭证及其目录不得向无关用户开放读取，账户管理证书不得作为运行前提。

#### Scenario: 以系统身份启动隧道
- **WHEN** 系统启动服务且当前 HOME 与安装者不同
- **THEN** 隧道仍读取指定配置和凭证并建立 connector，日志可确认注册连接，无需复制账户级 cert.pem

### Requirement: 常驻运行与启动前提透明
系统 SHALL 在卷已解锁且网络可用后自动启动隧道和应用，并对异常退出和暂时断网自动恢复。部署文档 MUST 明确 FileVault 锁定期间不能保证启动，不得要求关闭 FileVault 或开启自动登录作为默认方案；主机 SHALL 配置防系统睡眠并保留显示器睡眠。

#### Scenario: 解锁后无需手动启动
- **WHEN** Mac 重启并完成必要磁盘解锁，尚未手动运行任何项目命令
- **THEN** 系统服务自动启动，外网受邀用户可以进入；若卷仍锁定则验收记录明确标注前提未满足

### Requirement: 日志和健康诊断有界
系统 SHALL 提供最小存活检查、受保护的就绪诊断，以及有容量限制的应用和隧道日志。诊断 MUST 区分本地源站不可用、隧道无连接、身份拒绝与模型不可用，不泄露配置秘密；最小存活检查不得触发模型调用。

#### Scenario: 隧道连接失败可定位
- **WHEN** 本地源站正常但公网返回 530/1033
- **THEN** 运维流程检查显式配置、connector 与隧道日志，不以运行 PID 或空日志断言隧道已连接

### Requirement: 部署验收和回滚
部署 SHALL 在公网受保护之前完成本地认证和隔离验证，保留原配置备份及回滚说明；公网验收 MUST 同时验证匿名拒绝、有效邀请码、跨主体拒绝和额度限制。回滚到缺少防护的版本 MUST 同时关闭公网入口。

#### Scenario: 完整公网验收
- **WHEN** 运维人员使用独立移动网络验证部署
- **THEN** 登录页面可打开，匿名业务请求返回 401，有效邀请码可创建和读取自身评估，其他邀请码访问返回 404，超限请求被拒绝

#### Scenario: 撤回存在缺陷的版本
- **WHEN** 新版本身份或额度防护无法工作，需要恢复旧版本
- **THEN** 先关闭隧道公网入口，再恢复配置与应用，保留必要状态备份，不将旧的匿名业务 API 重新公开

### Requirement: 旧 connector 迁移有验证
迁移流程 SHALL 核对 Windows 旧 connector 是否仍承接该域名；仅服务同一目标且具备相同防护的副本可保留。文档 MUST 区分受支持的多副本与错误源站，不能将多个 connector 本身作为故障原因。

#### Scenario: Windows 副本仍指向旧应用
- **WHEN** 同一隧道上存在指向无防护旧应用的 Windows connector
- **THEN** 在公网验收前停用该旧副本或完成同等升级，确保请求不会绕过 Mac 上的防护
