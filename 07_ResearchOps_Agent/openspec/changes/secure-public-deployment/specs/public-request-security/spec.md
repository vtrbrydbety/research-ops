# Spec Delta

## Purpose

保护 ResearchOps 公网入口及其所在的个人主机，限制来自浏览器、直接 API 请求和外部材料的危险输入。使请求安全与外部访问策略在服务端生效，避免界面限制被绕过或将服务器环境误认为访客设备。

## ADDED Requirements

### Requirement: 公网禁用服务器环境探测
公网模式 MUST 禁用服务器环境授权签发及只读环境采集，包括直接 API、后台任务与研究工具路径；相关请求 SHALL 返回 403 或明确的能力不可用结果，且不得执行环境命令。页面 SHALL 保留手动和快照输入并说明对象为用户的复现环境。

#### Scenario: 绕过界面申请环境授权
- **WHEN** 已登录用户直接申请环境授权或提交只读环境检测请求
- **THEN** 返回 403，未执行主机探测；研究工具请求此能力时也不执行命令

### Requirement: 跨站请求保护
所有修改状态的浏览器请求 MUST 校验配置的同源 Origin；已登录请求还 MUST 校验会话绑定的 CSRF 令牌。登录请求 SHALL 校验 Origin 和 JSON 内容类型。公网模式 MUST 拒绝任意来源的凭证跨域访问及未经信任的 Host。

#### Scenario: 外站使用已有登录状态提交
- **WHEN** 浏览器携带有效 Cookie 从其他网站提交登录、退出、评估、反馈或最终决定
- **THEN** 返回 403 且无业务副作用；同源但 CSRF 缺失或错误的已登录写请求也被拒绝

### Requirement: 请求和响应边界
系统 MUST 对实际接收的请求体字节数设置上限，覆盖缺失或伪造 Content-Length 的请求；超限返回 413。公网响应 SHALL 设置禁止嗅探、禁止嵌入、限制来源的内容安全策略及隐私相关缓存策略，敏感 API 响应不得被共享缓存。

#### Scenario: 流式请求超限
- **WHEN** 客户端未提供 Content-Length 且发送超过配置上限的请求体
- **THEN** 返回 413，不解析完整负载、不创建评估或调用模型

#### Scenario: 页面与数据响应保护
- **WHEN** 用户加载页面及评估结果
- **THEN** 页面禁止第三方嵌入和未授权脚本执行，评估和会话响应包含 Cache-Control: no-store

### Requirement: 外部访问只连接允许的公网目标
所有由用户输入或模型工具产生的 HTTP 请求 MUST 限定允许的协议、端口和目标，拒绝 URL 内凭证、回环、私网、链路本地、保留地址及非公网 IPv6。每次重定向及实际连接 MUST 受同一策略约束，并保留响应大小、重定向次数和超时上限。

#### Scenario: 重定向和 DNS 变化不能访问内网
- **WHEN** 项目页面重定向到内网地址，或解析校验后 DNS 改变为私网地址
- **THEN** 请求在连接危险目标之前被阻止，不读取内网内容；已有提供商域名白名单继续生效

### Requirement: 不可信内容不能执行或泄露秘密
外部材料和模型内容 MUST 作为不可信文本渲染，不得在页面执行脚本或创建危险链接。邀请码、会话、CSRF、模型密钥及隧道凭证 MUST 不出现在 URL、常规日志、错误响应或版本控制中；业务审计 SHALL 仅记录必要的主体 ID、资源 ID、结果和请求关联信息。

#### Scenario: 恶意材料与失败诊断
- **WHEN** 外部材料包含脚本、危险 URL 或模型请求携带密钥后失败
- **THEN** 页面不执行材料内容，危险链接不可点击，日志及错误响应不包含凭证
