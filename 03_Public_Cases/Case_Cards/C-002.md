# C-002：发布的数据包和索引文件不完整

## 基本信息

- 来源：GitHub Issue（SCLBD/DeepfakeBench #13）
- 阶段：数据准备 / 数据预处理

## 原始问题

用户发现 DFDCP、Celeb-DF-v2 和 DFDC 的发布物存在视频、列表、JSON 条目或 metadata 缺失。

## 问题类别

路径与数据 / 发布物完整性。

## 用户影响

无法完整组织或预处理数据，后续可能出现样本遗漏和加载失败。

## 是否可提前发现

是。下载后对照 README 检查目录、文件数、索引和 JSON 引用即可提前发现。

## 处理结果

作者称已补齐文件并提供完整 JSON；但后续用户仍报告补充链接需要密码，因此仅记录为部分解决。

## 产品机会（推断）

【产品推断】自动生成数据资产清单，检查目录、压缩包、索引、metadata 和下载链接的完整性与可达性。
