# C-004：评测特征缓存导致内存溢出

## 基本信息

- 来源：GitHub Issue 回复链（SCLBD/DeepfakeBench #109）
- 阶段：评测运行 / 结果汇总

## 原始问题

用户使用约 90 GB 内存评测 DFDC 等大数据集时仍发生内存溢出，进程被系统直接终止。

## 问题类别

资源与性能 / 评测结果缓存。

## 用户影响

模型和数据已经能够加载，但大数据集评测无法完成。

## 是否可提前发现

部分。根据样本量和特征尺寸估算持续累积的 feature list，可以提前提示峰值内存风险。

## 处理结果

社区建议移除 `test_one_dataset` 中 feature list 相关内容；报告者和另一名用户均确认能够测试。

## 产品机会（推断）

【产品推断】运行前资源估算器可识别无界结果累积，并建议流式写盘、关闭非必要特征保存或仅保留聚合指标。
