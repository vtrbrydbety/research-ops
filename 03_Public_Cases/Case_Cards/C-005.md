# C-005：数据帧缺失引发索引越界和递归异常

## 基本信息

- 来源：GitHub Issue（SCLBD/DeepfakeBench #66）
- 阶段：数据加载 / 训练运行

## 原始问题

用户训练 LSDA 时反复出现 `list index out of range` 和 `maximum recursion depth exceeded`；回复将问题指向缺失视频或抽帧不足。

## 问题类别

路径与数据 / 数据完整性与异常重试。

## 用户影响

数据加载器不断换样本或递归调用，最终训练中断。

## 是否可提前发现

是。训练前核验 JSON 引用、文件存在性和每个视频的实际帧数可发现坏样本。

## 处理结果

社区建议补齐数据并重新生成 `FF++.json`，也有人修改 `__getitem__` 绕行；结果不一致，Issue 仍开放。

## 产品机会（推断）

【产品推断】准备度检查可核验索引、视频和最小帧数，并识别可能把坏样本放大为栈溢出的递归重试模式。
