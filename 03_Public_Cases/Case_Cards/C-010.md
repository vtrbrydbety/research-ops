# C-010：RuntimeError training SlowFast with custom AVA classes

## 基本信息

- 来源：GitHub Issue（open-mmlab/mmaction2 #670）
- 阶段：模型训练 / 时间采样

## 原始问题

自定义 AVA 数据训练 SlowFast 时，时间维度经采样后变为 0；增大 clip length 后又触发 CUDA 显存不足。

## 问题类别

配置耦合 / 时间采样与显存

## 用户影响

模型无法完成前向计算，调整后又因显存不足中断。

## 是否可提前发现

部分可以。静态计算 clip length、resample rate、speed ratio 各阶段的时间维度，并估算显存。

## 处理过程

回复建议降低 resample rate 或增大 clip length，同时通过降低采样参数、batch 或更换 GPU 处理 OOM，并检查自定义类别配置。

## 最终结果

部分解决；给出可行调参方向，但存在精度与资源权衡。

## 产品机会（推断）

【产品推断】配置检查器可联动验证时间维度、类别数和显存预算，提前提示相互冲突的参数。
