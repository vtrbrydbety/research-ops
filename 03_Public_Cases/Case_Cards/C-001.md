# C-001：RGB 图片输入与 LMDB 配置冲突

## 基本信息

- 来源：GitHub Issue（SCLBD/DeepfakeBench #110）
- 阶段：数据准备 / 训练启动

## 原始问题

用户按照 README 启动 Xception 训练时图片加载失败。排错发现配置使用 LMDB 读取模式，但传入的是 PNG 原图路径。

## 问题类别

路径与数据 / 数据格式配置不一致。

## 用户影响

训练数据无法加载，训练不能正常开始。

## 是否可提前发现

是。运行前核对数据存储格式、样本路径后缀与 `lmdb` 开关即可发现冲突。

## 处理结果

社区建议将 `train_config.yaml` 中的 `lmdb` 改为 `false`，用户确认修改后程序正常运行。

## 产品机会（推断）

【产品推断】准备度检查可交叉核验数据后端配置与抽样文件类型，在 LMDB 模式与实际文件类型冲突时提前阻断。
