# C-003：检测器权重与模型结构不匹配

## 基本信息

- 来源：GitHub Issue（SCLBD/DeepfakeBench #79）
- 阶段：模型初始化 / checkpoint 加载

## 原始问题

用户加载发布的 EfficientNetB4 detector checkpoint 时出现 state_dict 键缺失与多余，且不同模型存在系统性键名前缀差异。

## 问题类别

checkpoint 与配置 / 模型结构及权重命名。

## 用户影响

权重无法直接载入，模型测试或继续训练被阻塞。

## 是否可提前发现

部分。运行前比较 checkpoint 键名、张量形状、类别数和模型 `state_dict` 可发现不匹配。

## 处理结果

发起者提出先构建并调整模型，再以 `strict=False` 加载，并称已验证；Issue 仍开放，仓库级修复未确认。

## 产品机会（推断）

【产品推断】权重兼容性检查可生成键名和形状差异报告，并区分 backbone 权重与完整 detector 权重。
