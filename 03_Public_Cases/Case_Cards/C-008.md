# C-008：Optical flow inference requests nonexistent frame

## 基本信息

- 来源：GitHub Issue（open-mmlab/mmaction2 #904）
- 阶段：推理 / 光流输入

## 原始问题

对光流帧执行单视频推理时，工具错误计算总帧数并请求不存在的文件；简单修改 `start_index` 无效。

## 问题类别

输入计数 / 模态适配缺陷

## 用户影响

光流模型推理直接失败。

## 是否可提前发现

是。读取输入目录后按模态核对文件命名规则、x/y 光流对数和最大索引即可发现。

## 处理过程

讨论确认 `inference_recognizer` 对光流总帧数计算有缺陷；用户以文件数除以 2 绕过，贡献者提出按文件名和模态计算的修复。

## 最终结果

已解决；用户确认修复方向有效。

## 产品机会（推断）

【产品推断】输入检查器应识别 RGB 与光流模态，按真实文件模式计算有效帧数而非沿用统一逻辑。
