# C-012：SlowFast custom data mAP remains zero

## 基本信息

- 来源：GitHub Issue（open-mmlab/mmaction2 #732）
- 阶段：训练评估 / 自定义 AVA

## 原始问题

受硬件限制将 clip length 调低后，自定义 SlowFast 训练多轮 mAP 始终为 0，并伴随类别数断言和显存约束。

## 问题类别

训练配置 / 指标异常

## 用户影响

训练虽能运行，但模型没有产生有效检测结果，计算成本被浪费。

## 是否可提前发现

部分可以。可在正式训练前检查类别映射、clip 配置、batch 与学习率，并进行短程过拟合测试。

## 处理过程

回复建议核对配置，使用更轻的 SlowOnly，设置较小 batch；若恢复 clip length，应同步降低 batch 和学习率。

## 最终结果

未确认；获得诊断和配置建议，但没有用户最终成功记录。

## 产品机会（推断）

【产品推断】提供小样本过拟合与早期指标守门，在 mAP 长期为 0 时自动检查类别映射和关键训练参数。
