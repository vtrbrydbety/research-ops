# C-017：CUDA device-side assert during custom dataset training

## 基本信息

- 来源：GitHub Issue（facebookresearch/detectron2 #2365）
- 阶段：模型训练 / 标签映射

## 原始问题

自定义数据训练出现 CUDA device-side assert，异步堆栈难以直接定位。

## 问题类别

标签质量 / 类别 ID 越界

## 用户影响

训练崩溃，且 CUDA 异步报错掩盖真实数据问题。

## 是否可提前发现

是。可在上 GPU 前验证所有 category_id 是否位于连续合法范围。

## 处理过程

维护者建议设置 `CUDA_LAUNCH_BLOCKING=1` 获取准确位置，随后发现数据中存在 333，而模型只预期 0～2。

## 最终结果

已定位并解决根因。

## 产品机会（推断）

【产品推断】数据校验器应检查类别 ID 范围、连续性和映射表，并为 CUDA 异步错误提供诊断模式。
