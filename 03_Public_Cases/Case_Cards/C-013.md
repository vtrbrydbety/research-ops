# C-013：Panoptic segmentation cannot export ONNX

## 基本信息

- 来源：GitHub Issue（facebookresearch/detectron2 #4354）
- 阶段：模型导出 / ONNX

## 原始问题

按官方命令导出全景分割模型时，无法从 `detectron2.export` 导入 `Caffe2Tracer`。

## 问题类别

API 兼容性 / 导出工具缺失

## 用户影响

官方导出流程无法启动，模型不能进入后续部署验证。

## 是否可提前发现

是。可在执行前检查安装版本是否包含文档引用的导出类和依赖。

## 处理过程

讨论指出相关修复仍在 PR 中，多名用户报告相同问题；原作者明确表示问题未解决。

## 最终结果

未解决；Issue 仍开放。

## 产品机会（推断）

【产品推断】将文档命令与已安装包 API 做预检，并标注尚未发布或已移除的接口。
