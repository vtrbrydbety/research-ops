# C-009：Single GPU training hangs

## 基本信息

- 来源：GitHub Issue（open-mmlab/mmaction2 #421）
- 阶段：训练启动 / 数据加载

## 原始问题

单 GPU 训练停在数据加载阶段，没有继续输出；将 `workers_per_gpu` 设为 0 后恢复。

## 问题类别

系统资源 / 多进程共享内存

## 用户影响

训练看似卡死，用户难以判断是程序故障还是资源不足。

## 是否可提前发现

部分可以。可检测容器或主机共享内存大小，并根据 worker 数和样本体积估算风险。

## 处理过程

回复将问题定位为多进程 DataLoader 的共享内存不足，建议降低 worker 数；用户确认设为 0 可运行。

## 最终结果

已解决。

## 产品机会（推断）

【产品推断】启动前检查 `/dev/shm`、worker 数和 batch 配置，并给出安全初始值。
