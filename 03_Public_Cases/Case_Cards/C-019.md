# C-019：Cannot build detectron2

## 基本信息

- 来源：GitHub Issue（facebookresearch/detectron2 #2090）
- 阶段：环境安装 / 源码编译

## 原始问题

通过 pip 从源码安装 Detectron2 时发生 C++/NVCC 编译错误。

## 问题类别

编译工具链兼容

## 用户影响

依赖无法安装，后续模型运行完全阻塞。

## 是否可提前发现

是。可在编译前比对 PyTorch CUDA、NVCC、GCC 和 Ninja 版本。

## 处理过程

维护者指出 NVCC 必须匹配 PyTorch CUDA，且 NVCC 与 GCC 组合需兼容；社区还报告升级 Ninja 后成功。

## 最终结果

部分解决；根因范围明确，并有成功版本组合记录。

## 产品机会（推断）

【产品推断】环境检查器应同时验证 PyTorch CUDA、系统 CUDA、编译器和构建工具，而非只记录 CUDA 版本。
