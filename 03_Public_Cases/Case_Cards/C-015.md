# C-015：ImportError: cannot import name _C

## 基本信息

- 来源：GitHub Issue（facebookresearch/detectron2 #1018）
- 阶段：环境启动 / 扩展导入

## 原始问题

运行 PointRend 或 DensePose 示例时无法导入 Detectron2 编译扩展 `_C`。

## 问题类别

安装路径 / 本地包遮蔽

## 用户影响

模型组件无法加载，示例不能启动。

## 是否可提前发现

是。可检查当前工作目录、实际导入路径和扩展文件是否来自同一安装。

## 处理过程

维护者指出用户在源码仓库根目录运行，未编译源码遮蔽了已安装包；建议离开该目录并按安装文档确认安装。

## 最终结果

根因和处理方法明确；Issue 已关闭。

## 产品机会（推断）

【产品推断】启动诊断应打印模块真实加载路径，并检测源码目录遮蔽已安装包的情况。
