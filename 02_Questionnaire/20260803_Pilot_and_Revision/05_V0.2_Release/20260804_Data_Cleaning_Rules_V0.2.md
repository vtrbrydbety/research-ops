# ResearchOps 数据清洗规则 V0.2

- 适用问卷：ResearchOps 用户调研问卷 V0.2
- 生效日期：2026-08-04
- 上一版本：V0.1.1
- 原则：保留原始数据，不直接覆盖用户原始答案

## 一、数据分层

- `virtual_precheck`：虚拟用户预检数据，不进入正式统计。
- `real_pilot`：真实用户预测试数据，不进入正式统计。
- `formal`：正式发放数据，可在清洗后进入正式分析。

## 二、样本资格

### Q1

- Q1=1：核心有效路径。
- Q1=2：核心有效路径。
- Q1=3：结束路径，不进入核心问题统计。
- 选择 Q1=3 但后续题仍有回答：标记跳转异常并人工复核。
- Q1 缺失：标记为资格未知，不直接纳入核心统计。

## 三、重复与异常答卷

以下规则沿用 V0.1.1，不自行新增或调整数值阈值：

| 检查项 | 判定规则 | 处理方式 |
|---|---|---|
| 重复提交 | 提交时间、设备、联系方式或回答内容高度重复 | 保留内容更完整的一份，其余标记为重复；原始答卷均保留 |
| 答题时长异常 | 完成时间明显低于正常阅读与作答时间 | 先人工复核，不直接删除；具体阈值在获得足够真实数据后确定 |
| 前后矛盾 | 关键题之间出现无法直接解释的逻辑冲突 | 保留原始回答，标记 `manual_review=1`，人工核查后决定是否纳入 |
| 明显乱填或机器灌水 | 连续机械选择、无意义字符、规律性作答或答案明显自相矛盾 | 人工复核后标记；不因单一信号自动删除 |
| 关键字段缺失 | 核心样本的资格、结果、时间或关键研究变量大面积缺失 | 不纳入核心统计，但保留原始数据和处理记录 |

### 人工复核原则

1. 原始数据只读保存，不直接覆盖。
2. 清洗后的数据另存为新文件。
3. 所有删除、改码、排除和异常处理均进入清洗日志。
4. 任一清洗规则要求人工核查时，`manual_review=1`。
5. 只有在人工复核并记录依据后，才决定答卷是否排除。

## 四、Q7—Q8 一致性规则

当以下条件同时出现时：

- Q7 = 完整跑通并达到接近目标的结果；
- Q8 = 尚未获得可用结果；

执行以下处理：

- `consistency_flag=1`；
- `manual_review=1`；
- 保留 Q7 和 Q8 原始回答；
- 结合 Q9、Q10、Q11、Q17 进行人工复核；
- 不自动删除答卷。

未触发时，`consistency_flag=0`。`manual_review` 是否为 1 仍由其他清洗规则共同决定。

## 五、Q9 与 Q10

Q9 和 Q10 测量不同维度：

- Q9：投入总时间最多；
- Q10：最容易停滞或无法继续。

两者答案不同不视为矛盾。

例如：

- Q9=运行训练、推理或测试；
- Q10=获取数据集或预训练权重；

属于合理回答，不触发一致性异常。

## 六、Q11 多选互斥

- `q11_late_issue_none=1` 时，Q11 所有其他问题子变量必须为 0。
- 任一其他 Q11 问题子变量为 1 时，`q11_late_issue_none` 必须为 0。
- 出现共选时，保留原始值并标记 `manual_review=1`。
- 不自动推断用户实际想选择哪项。

其他互斥规则继续保留：

- Q12 的“没有使用以上方式”与其他方式互斥；
- Q13 的“没有明显不足”与其他不足互斥；
- Q16 的“不会使用或分享这类报告”与其他使用或分享方式互斥。

命中任一互斥冲突时，均保留原始值并进入人工复核。

## 七、Q17 开放文本

Q17 包含以下四个字段：

- `q17_project_task`
- `q17_main_blocker`
- `q17_attempted_methods`
- `q17_expected_information`

处理规则：

- 四个字段均允许为空；
- 四项全部为空不单独判为无效答卷；
- 不因文字较短直接删除；
- 明显无意义、复制粘贴或与问题完全无关时，进入人工复核；
- 原始文本不得被清洗后的摘要覆盖。

## 八、清洗日志字段

每次人工处理至少记录：

- `response_id`
- `questionnaire_version`
- `data_source`
- `triggered_rule`
- `original_value`
- `consistency_flag`
- `manual_review`
- `review_decision`
- `review_reason`
- `reviewer`
- `review_date`

## 九、输出文件命名

- 原始数据：`20260804_Questionnaire_Raw_V0.2`
- 清洗数据：`20260804_Questionnaire_Clean_V0.2`
- 清洗日志：`20260804_Cleaning_Log_V0.2`
